# TrackChain Family - Blockchain Finance Tracker

A modern, mobile-first UI design for a blockchain-powered family finance tracker with AI-based expense analysis.

## 🎨 Design Overview

**TrackChain Family** is a cutting-edge mobile application that combines blockchain technology with AI-powered financial insights to help families track and manage their expenses transparently and securely.

### Key Features

- **🔗 Blockchain Security**: Every transaction is verified and immutable
- **🧠 AI Analysis**: Smart expense categorization and spending insights
- **👨‍👩‍👧‍👦 Family Focus**: Multi-role support for different family members
- **📱 Mobile-First**: Optimized for mobile devices with responsive design
- **🎯 Real-time Updates**: Live balance and transaction updates

## 🎨 Design System

### Color Palette
- **Primary Blue**: `#0D1B2A` - Deep, trustworthy background
- **Accent Teal**: `#00C2A8` - Modern, tech-forward accent
- **Accent Gold**: `#FFD166` - Premium, valuable highlights
- **White**: `#FFFFFF` - Clean, readable text
- **Success Green**: `#28A745` - Positive financial indicators
- **Warning Orange**: `#FFC107` - AI alerts and notifications
- **Danger Red**: `#DC3545` - Expense indicators

### Typography
- **Font Family**: Poppins (Google Fonts)
- **Headers**: Bold, 600-700 weight
- **Body Text**: Regular, 400-500 weight
- **Clear hierarchy** with consistent spacing

### Visual Elements
- **Rounded Corners**: 16px for cards, 8px for small elements
- **Soft Shadows**: Layered shadow system for depth
- **Smooth Animations**: 0.3s cubic-bezier transitions
- **Glass Morphism**: Backdrop blur effects for modern feel
